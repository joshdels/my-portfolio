What I do

Practical GIS work, from source data to a useful output.

I enjoy the practical side of GIS: preparing data, making maps, checking the details, and helping turn a workflow into something repeatable and easy to hand over.

Map production

Clear report maps and browser-based map experiences with readable symbology, sensible layout, and the source and projection details people need.

Spatial data preparation & QA

Organize layers and attributes, check coordinate systems, review counts and geometry, and leave a clear record of the changes made.

Analysis & GIS/CAD workflows

Buffers, overlays, area calculations, map updates, and preparation of CAD information for GIS using known units and coordinate references.

Core stack

QGIS · ArcGIS ecosystem · AutoCAD · Python · PostGIS · Django · Leaflet / JavaScript web mapping. The project pages show how I have used these tools and what I learned from the work.
